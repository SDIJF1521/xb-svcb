# 🎉 XB-SVCB v0.1.2 リリースノート

#### ワークフローストア登場：共有・プレビュー・ダウンロード・PyMSS 連携

[![release](https://img.shields.io/badge/release-v0.1.2-ff6b9d?style=flat)](../../README.ja.md)
[![date](https://img.shields.io/badge/date-2026--11--21-informational?style=flat)](#)

</div>

> **ひとことで：** ModelScope（魔搭社区）を利用したワークフローストアを追加しました。カバーワークフローのアップロード、ページ分割検索、読み取り専用プレビュー、ダウンロードに対応し、ダウンロード時にはマニフェストに記載された PyMSS モデルを自動で同期します。ダウンロードしたワークフローは AI カバーワークベンチで直接読み込めます。ワークフロープレビューと全画面の確認ダイアログも刷新し、ダウンロードしたワークフローの有効な接続が削除される問題を修正しました。

## 🔧 リリース後の修正と改善（v0.1.2 · 2026-11-21 → 11-27）

リリース後に追加した修正です。MIDI ピッチ編集とカスタムワークフローキャンバスが中心です：

### 🎼 MIDI サブエディター

- **音符を削除するとミュート**：「ピッチ補正」モードで音符を削除すると、その歌唱区間が試聴と適用後に実際にミュートされます（従来は元の歌声がそのまま鳴っていました）。エディターは抽出時の音符スパンを参考歌唱区間（sidecar の `voice_spans`）として記録し、現在の音符で覆われていない部分をミュートします。すべて削除すると歌声全体がミュートされます（息継ぎや子音など非有声部分は残ります）。
- **空の音符リストを保存可能**：全音符を削除して保存した後、開き直しても再解析で音符が戻りません。音符が 0 個でも「音符を保存」「音声を適用」が使え、`midi/apply` に明示的な空配列を渡すと抽出済みの歌唱区間をすべてミュートできます。
- **トラック試聴が MIDI 再描画を使用**：トラック範囲の「試聴」は、クリップごとに再描画して 1 本のトラック長プレビューに合成する方式になりました。再生ヘッドはピアノロールのトラック時間軸と揃い、削除した音符も試聴で確認できます。
- **ピッチカーブを一筆ごとに分割**：手描きカーブは一筆単位のセグメントとして保持します。同一の筆の中は連続、筆と筆の間は補間せず、描いていない区間は元の F0 に戻ります。後から描いた筆が、描いていない区間を直線で結ぶことはありません。
- **「続けて描く」スイッチを追加（既定オフ）**：新しい筆が既存セグメントの端点に近い場合に接続し、連続を保ちます。両端が近い場合は両方に接続でき、途中の隙間を埋めるのに便利です。
- **部分的な描き直しと消去**：新しい筆は覆った時間範囲で古いセグメントを分割し（境界は補間して補点）、両側は残しつつ強制的には接続しません。消しゴムもセグメントを分割するだけで、穴をまたいで補間しません。元に戻す / やり直しはセグメント単位で復元します。手描きサンプルは必要に応じて間引き、1 音符 256 点の上限で長い音符の末尾が切れる問題も解消しました。

### 🧩 カスタムワークフローキャンバス

- **「詳細設定」を展開しても接続線がずれない**：ポート位置をノードのサイズに追従して再測定します。セクションの開閉やモデル切り替えでパラメータ領域の高さが変わっても、接続線の端点は常に下部の出力ポートに付きます。
- **パフォーマンス**：1 つの `ResizeObserver` で全ノードを監視し、アニメーションフレーム単位でまとめて処理します。再測定するのはサイズが変わったノードだけ、ポート位置が変わらなければ接続線の再計算も行いません。ホイール拡大縮小では毎フレーム強制レイアウトせず（ポート偏移は拡大率に依存しません）、操作が止まってから 1 回だけ再測定します。

## 🛍️ ワークフローストア

- 「ライブラリ → ワークフローストア」から開きます。ModelScope のアクセストークンはモデルストアと共有します。
- 保存済みワークフローを、ノードグラフ・説明・タグ・バージョン・作者・必要な PyMSS モデルとともにアップロードできます。
- キーワード検索、すべて／自分が投稿したワークフローの絞り込み、ページサイズ変更、ページ送りに対応。ページャーはページ下部に固定されます。
- ページ総数はワークフローのリポジトリのみを数え、自分の音声モデルは「自分が投稿したワークフロー」に含めません。
- マニフェストの magic 検証に合格したワークフローだけを表示し、無関係なモデルを除外します。

## 🔗 PyMSS とワークベンチの連携

- ワークフロー詳細に関連 PyMSS モデルとローカルのインストール状態を表示します。
- ダウンロードはまず「保存済みワークフロー」に書き込み、その後不足している PyMSS モデルをインストールします。失敗した項目は転送パネルに表示され、後で再試行できます。
- 「AI カバーワークベンチへ」はローカルワークフロー ID を引き継ぎ、カスタムワークフローモードでそのワークフローを読み込みます。
- ダウンロードしたワークフローは初回表示時に自動整列し、作者の元の配置による交差を軽減します。元に戻す操作で復元できます。

## 🖼️ プレビューとダイアログ

- プレビューは作者のキャンバス座標ではなく、トポロジーに基づく階層レイアウトを使用します。
- ノードタイトルは 1 行で省略し、パラメータ説明は最大 2 行で折り返すため、モデル名がカードからはみ出しません。
- 方向矢印、テーマ対応の背景・カード、グラフに応じた高さ調整を採用しました。
- すべての `ElMessageBox` を flex 中央配置・明示的な幅・テーマ付きボタンに統一し、一部環境で確認ダイアログが左上に出る／透明になる／ボタンがずれる問題を修正しました。
- `el-dialog` もガラス背景、角丸、影、ぼかしオーバーレイで統一しました。

## 🔧 重要な修正

- PyMSS モデルカタログの準備前にダウンロード済みワークフローを開くと、音軌が不明なポートを失効扱いにして有効な接続を削除していた問題を修正しました。
- モデルカタログ読み込み後にポート位置を再測定し、接続線がノードの角に落ちる問題を修正しました。
- 接続 ID の欠落・重複時に一意な代替 ID を生成し、Vue の key 再利用による描画崩れを防止しました。
- 「自分が投稿したワークフロー」の件数に音声モデルが混ざる問題を修正しました。
- 一部テーマ／環境での MessageBox レイアウト問題を修正しました。

## 🧱 アーキテクチャと品質

- `domain/workflow_manifest.py` を追加：マニフェスト検証、ノードグラフの安全な整形、PyMSS 依存解析、来源情報の正規化。
- `infrastructure/workflow_hub_client.py` を追加：ModelScope 検索、マニフェスト取得、子プロセスによるアップロード。
- `application/workflow_hub_service.py` はユースケース編成のみを担当。PyMSS のインストール状態は `PymssGateway` ポート経由で参照します。
- ドメイン／ユースケース／ポート契約のテストを追加し、DDD アーキテクチャ文書も更新しました。

## 📌 アップグレード時の注意

- バージョンは `0.1.2` です。既存のデータディレクトリ、モデル、作品、エディタープロジェクトと互換性があります。
- 旧バージョンでダウンロード済みワークフローを開き、接続が削除された状態で保存した場合、アップグレード後に再ダウンロードすると完全な接続に戻ります。
- ワークフローのアップロードには `.venv-hub` のアップロードコンポーネントが必要です。検索・プレビュー・ダウンロードには不要です。
