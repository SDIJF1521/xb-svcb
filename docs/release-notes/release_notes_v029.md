## v0.0.29 · 实时翻唱、系统音频变声与 AI 增强工作流

> v0.0.29 把实时翻唱从单纯的文件转换扩展为可用于播放器场景的系统音频变声器：输入 QQ 音乐等播放器输出的混合音频，只转换人声并保持伴奏与原始时钟对齐。同时补齐 AI 歌声增强独立工程、编辑器片段增强、临时文件回收和 VB-CABLE 安装引导。

### 🎙️ 实时翻唱与系统音频变声

- 新增“实时翻唱”工程页，支持歌曲文件实时播放和系统音频变声两种输入模式。
- 系统音频模式支持 WASAPI 回环、VB-CABLE、Voicemeeter 等混合输入设备；自动排除麦克风，输出设备必须与输入设备分离，避免回授和重复采集。
- 系统混音输入保留原始伴奏，只将 UVR 提取的人声送入单个 RVC 或 SeedVC 模型转换，再与对应时间块的伴奏重新混合输出；系统音频模式明确限制为单模型，不支持多模型分段或合唱。
- UVR 与 RVC/SeedVC 使用常驻推理会话和采集、分离、转换、播放流水线，音频块带固定缓冲，减少每个块重复加载模型造成的卡顿。
- 相邻音频块增加约 40 ms 重叠上下文，并在最终混音输出处使用等功率交叉淡化；不缩短时间轴，避免硬拼接产生的咔哒声、断点和衔接不自然。
- 静音、暂停和恢复场景保持系统音频时钟连续；录音设备出现 `data discontinuity` 时不再把警告直接刷到用户界面。
- RVC 参数支持 F0 算法、推理设备、模型版本、Index、RMS、保护和滤波半径；SeedVC 支持参考音频、扩散比例和推理设备。块时长、预缓冲、输入/伴奏增益也可调整。
- 实时会话完成后自动登记到“我的作品”；文件模式支持分块播放和导出，系统音频模式支持直接监听输出。

### 🎧 AI 歌声增强与编辑器集成

- 新增独立 AI 增强工程页面，原始歌曲可以来自本地导入，也可以使用在线曲库下载的原始音频。
- 增强任务保留原始歌曲依赖关系，并将处理结果保存到“我的作品”；增强后的作品可继续进入音频编辑器。
- 音频编辑器支持对选中片段调用 AI 增强，使用对应原始音频作为参考；增强失败不会破坏原片段，可通过撤销恢复。
- 编辑器片段增强与整曲增强共用增强参数和作品持久化逻辑，降低重复配置和文件残留风险。

### 🧹 文件生命周期与关闭清理

- 软件退出时先停止实时翻唱、UVR、RVC/SeedVC 和 HTTP 后台服务，再清空当前用户数据目录下 `temp` 的全部文件和子目录，保留 `temp` 目录本身。
- 临时目录清理增加路径边界校验、Windows 文件占用重试和符号链接安全处理，避免误删数据目录外内容。
- 实时会话、编辑工程和作品删除流程继续清理关联生成文件、编辑缓存和临时中间文件，减少 `temp`、`editor` 目录残留。

### 🛠️ 安装器与界面修复

- 安装器前置依赖页新增 VB-CABLE 检测；缺失时提供用户手动安装入口，不会静默安装虚拟声卡驱动，安装完成后可重新检测。
- 实时翻唱设备错误统一通过 Element Plus 消息组件提示，输入输出设备相同、未发现系统混合输入等问题会显示明确原因。
- 修复 Element Plus `ElMessage` 按需样式缺失导致错误消息显示为未样式化黑色横条的问题。

### 📦 升级与兼容

- 应用本体、Python 项目、前端包、两份锁文件、Windows EXE 版本资源、Inno Setup 和安装器文档统一为 `0.0.29`。
- 升级不会迁移或删除用户的模型、作品、编辑工程、主题媒体、API 设置和插件数据；关闭时只清理数据目录下的临时生成内容。
- 系统音频变声需要 Windows 音频回环或虚拟音频线。安装 VB-CABLE 后，请将 QQ 音乐输出切换到对应虚拟线路，再在实时翻唱页刷新设备并选择独立的播放输出设备。
