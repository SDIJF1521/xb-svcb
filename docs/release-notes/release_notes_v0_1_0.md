# XB-SVCB v0.1.0 更新说明

**简体中文** | [English](release_notes_v0_1_0.en.md) | [日本語](release_notes_v0_1_0.ja.md)

`0.1.0` 是 XB-SVCB 首个同时提供简体中文、English、日本語应用界面、安装器和发布说明的版本。本版集中改进创建流程、音频编辑器、推理保护、主题系统和发布方式，并将应用及安装器版本统一提升到 `0.1.0`。

版本变更范围从提交 `fc8d214e068457a273929e80c108b33f55b4e9e8`（“全参数说话人输入框改选项框”）开始，并包含该提交。生成提交列表或审计差异时应使用：

```text
fc8d214e068457a273929e80c108b33f55b4e9e8^..HEAD
```

从 `0.1.0` 开始，每个新版本必须同步提供简体中文、英文和日文发布说明；三份说明描述同一发布范围和兼容性要求。

## 界面与多语言

- 新增简体中文、English、日本語界面切换。选择结果会持久化，并在 Vue 页面和 Element Plus 组件初始化前生效，减少启动时语言闪烁。
- 首页、创建页、编辑器、作品、模型、插件、人声增强和 API 管理等主要工作流补齐英文与日文文案。
- 针对英文和日文较长标签调整按钮、选择器、表单和编辑器面板布局，避免翻译后文字截断或覆盖相邻控件。
- 首次使用引导由 37 个零散步骤整理为 10 个工作流步骤，保留模型准备、创建任务和编辑导出的关键操作。
- 修复主题切换时页面宽度变化造成的水平抖动，并改进主题过渡期间的窗口背景同步。

## 创建与推理

- 全参数模式中的说话人由自由输入改为模型提供的选项框。So-VITS-SVC 会读取模型配置中的说话人名称，DDSP-SVC 会按模型声明的说话人数量生成编号，减少名称或 ID 输入错误。
- 模型配置损坏、说话人数量异常或未提供说话人列表时会安全回退为空选项，不再生成不可用的大型列表。
- 普通翻唱的高音保护默认由系统接管：开启全参数且保护轮次设为 `0` 时，使用默认保护轮次；实时翻唱继续保留 `0` 表示不重试的兼容语义。
- 高音保护会在极高音区域先执行保共振峰降调，模型推理后再升回原调并补偿响度；失败重试会根据实际哑音位置调整保护起点。
- 补充 RVC v1/v2 模型结构识别和兼容提示；无法可靠识别时保留兼容设置并给出警告，不静默改写模型版本。
- API 页面同步公开高音保护、全参数调节和编辑器局部重推理字段，并补充取值范围、默认值与普通/实时模式差异。

## 音频编辑器

- 时间线空白区域、音轨和片段新增右键菜单，常用的片段、音轨与效果操作可以直接在当前位置执行。
- 效果器改为片段、整轨和角色三个独立作用域；各作用域可单独启用、旁通、调整和移除效果，并在渲染时保持各自的路由边界。
- 扩充内置音频处理与插件工作流，增加作用域效果总线、插件编辑器同步、监听预览以及异常插件自动旁通保护。
- 局部重推理新增阶段进度、状态说明和持续追加的运行日志。任务进行中即可查看模型校验、推理和片段替换阶段，不必只等待最终成功或失败结果。
- 重推理完成后保留适用的片段效果；不适合直接复用的插件效果会记录到工程元数据，避免旧处理链被无提示地重复应用。
- 优化编辑器面板、时间线选择、作品列表和播放页面的交互与响应式布局。

## 主题与资源

- 新增和调整内置主题，并替换默认品牌资源；应用和安装器图标统一使用 `web/public/favicon.ico`。
- 自定义主题背景支持 JPG、PNG、WebP、GIF、AVIF、HEIC/HEIF 和 MP4。背景媒体保存到应用主题目录，不再受浏览器本地存储大小限制。
- 较大的静态图片会通过 FFmpeg 自动缩放和转换，降低启动内存与项目配置体积；媒体路径限制在主题目录内，删除主题时不会误删外部文件。
- 自定义背景支持遮罩强度、图片/视频类型和粒子参数，并在主题切换后同步窗口边框颜色。

## 安装器与在线安装

- 离线安装器支持简体中文、English、日本語。启动时按 Windows UI 语言预选，并始终允许用户切换语言。
- 安装向导、依赖检查、硬件栈选择、内置 Python 校验、数据目录选择、安装进度、错误提示、运行时校验、完成页及快捷方式全部使用同一套三语消息键。
- 五套离线安装器现在都内置干净的 64 位 CPython 3.12.x 和完整 FFmpeg/ffprobe，不再依赖用户机器上的全局 Python 或 FFmpeg；安装及后续修复固定使用安装目录中的运行时。
- 修复 CUDA 共享运行时在低端或首次冷启动较慢的显卡上因 DDSP 导入超过 45 秒而误报失败的问题；共享安装器现在对普通导入允许 90 秒，对 DDSP 冷启动允许 180 秒，超时仍会明确记录并阻止激活不完整的 `runtime.json`。
- 简体中文和日语 Inno Setup 语言文件随源码提供，构建不依赖开发机是否安装额外语言包。
- 新增轻量在线安装器，可检测 CPU、NVIDIA CUDA 12.6/12.8、AMD ROCm 10，并提供 DirectML 兼容模式选择；它只下载用户选择的一套离线安装包。
- DirectML 安装包恢复携带 `pymss/py312/cpu`：PyMSS 在独立 `.venv-pymss` 中使用 CPU Torch 2.7.1，不与固定 Torch 2.4.1 的 `torch-directml` 混装。
- 在线清单固定五套离线安装器 EXE/BIN 的文件大小和 SHA-256，在线安装器再固定清单 SHA-256；全部校验通过后才启动离线安装流程。
- OSS 地址在构建时通过公开 HTTPS URL 注入，安装器不包含 AccessKey、Secret 或长期签名 URL。
- 五栈 wheelhouse 改为增量补齐。只有显式使用 `-CleanWheelhouse` 才会删除缓存，网络中断后可以从指定批次继续。
- CPU 的 SVC/RVC 组件在 ROCm 批次前准备，避免 AMD 下载源失败导致 CPU 安装包后续才发现目录为空。
- ROCm 组件通过硬链接复用公共 Torch/SDK wheels，减少 PyMSS、DDSP 等组件重复下载和占用磁盘空间。

## 模型与仓库

- Git 仓库不再跟踪 `assets/models/` 中的模型权重、清单和配置。模型由外部模型社区维护，发布构建前需要同步到本地 `assets/models/`。
- 离线安装包仍可携带发布者本地准备的完整模型目录；仓库忽略规则不会阻止安装器读取这些本地文件。
- 模型、作品、编辑工程、主题、API 设置和插件数据继续使用原数据目录，覆盖升级不会主动删除用户数据。

## 开发与文档

- 根 README、用户文档、开发文档、API 文档和插件文档提供简体中文、英文与日文入口。
- Python 服务层、基础设施、安装脚本和 wheelhouse 工具补充类型注解，并加入 Pyright 配置，便于在发布前发现接口类型漂移。
- 新增界面翻译键一致性、安装器三语消息、RVC 模型识别、推理设备、主题媒体、编辑器效果作用域和安装器运行时计划等检查。
- 后端、Python 包与锁文件、前端与锁文件、PyInstaller 版本资源及安装器版本统一为 `0.1.0`。

## 兼容性与升级提示

- 继续使用 Python 3.12 和硬件专用运行时布局，提供 CPU、ROCm 10、DirectML、CUDA 12.6 与 CUDA 12.8 五种安装配置。
- DirectML 主要用于兼容推理。DDSP 自动设备仍优先使用 CPU；显式选择 DirectML 的实验路径需要试听确认输出。
- 在线安装器需要访问发布者配置的 OSS/HTTPS 地址；需要完全离线部署时应下载对应硬件栈的 EXE 和全部同名前缀 BIN 分卷。
- 从旧版本升级前建议保留用户数据目录备份。安装器不会迁移或删除已有模型、作品和编辑工程，但外部模型目录必须由发布者或用户自行维护。

安装与修复步骤见[源码安装与启动](../getting-started.md)，安装器构建、在线发布和 OSS 配置见[安装器文档](../../installer/README.md)。
