## 🎼 MIDI サブエディター

- **ノート単位のピッチ再描画**：クリップ音声からノートを抽出し、ノートごとにピッチを音声へ再描画します。再描画は分離されたボーカル用ランタイムで Praat PSOLA により実行され、フォルマントと音色を保ち、ドラッグしたノートだけを変更します。未変更のノートは元のピッチを保ちます。
- **2 つのモード**：「ピッチ補正」は既存の歌唱を補正し、「MIDI 作曲」はゼロから譜面を書きます。作曲モードには 128 の GM 音源と GM ドラムキットを内蔵し、ドラムは `gm.dls` から抽出した実サンプルを使用、キック / スネア / ハイハット / シンバルなどのグループにスナップします。
- **完全なタイムライン**：BPM・拍子・長さ・グリッド・クオンタイズ強度に対応。長さは手入力でき（最大 24 時間）、ノートを先に書けば自動で伸びます。空プロジェクトの入口を追加し、空トラックでも直接作曲して音声を生成できます。
- **作業効率**：右クリックメニュー（追加 / 削除 / コピー / 貼り付け / クオンタイズ / 移調 / ベロシティ / レガート / 分割 / 全選択 / 元に戻す・やり直す）とショートカット（`D` ペン、`V` 選択、`E` 消しゴム、`Ctrl+C/V/D/A/Q/Z`、`Alt+↑↓`、`Shift+↑↓`、`Del`、スペースで試聴）、さらに「このトラックにレンダリング」「楽器ごとに音声トラックを作成」「.mid を書き出し」「.mid をパートにインポート」。
- **ピッチカーブ（ポルタメント / ビブラート）**：音符上をドラッグすると、実際に歌われた基頻の上にカーブを描けます。「ビブラート」「ポルタメント」「元のピッチを取得」「カーブを消去」も用意し、元の F0 を初期値として段階的に編集でき、すべて元に戻す / やり直しに対応します。
- **部分的な整形**：指定位置でノートを分割でき、その切れ目でピッチカーブも切断されるため、部分的な区間だけを個別に整えられます。
- **絶対目標ピッチで再描画**：カーブが目標ピッチそのものを示すため、歌い手自身のずれを二重に適用しません。既定カーブをレンダリングした際に本来存在しないポルタメントが出る／ビブラートが強調される問題を修正しました。
- **参照ピッチの品質向上**：元の F0 は事前に外れ値処理（局所メディアンフィルタでフレーム単位のオクターブ跳びや爆音を除去）を行い、参照カーブとして重ねて表示するため、「実際に歌われたピッチ」と「ノートのピッチ」を比較できます。

## 🎚️ オーディオエディター

- **トラック名の変更**を追加しました。
- **エクスポートパス欄がタイムライン上部を押し広げてツールバーを潰す問題**を修正しました。狭い画面では折り返し、長いパスは省略表示にします。
- **ロールの「移調」が実際にレンダリングへ反映**されるようになりました。0 以外の移調を持つロールは専用バスを通り、長さを保ったまま移調されます。さらにミックスキャッシュの署名に含めたため、変更後に古いキャッシュが再利用されません。
- 画面上部の**メッセージをナビゲーションバーの下へ移動**し、ヘッダーや検索欄を覆わないようにしました。
- エディター全体の操作感、VST3 プラグインホスト、ロールエフェクトのスコープ、部分再推論の細部を調整しました。

## 🧩 AI カバーワークスペース：カスタムワークフロー

キャンバス上で自由に接続し、カバーの処理工程をそのまま組み立てられます：

| 分類 | ノード |
| :--- | :--- |
| 入力 / 出力 | 入力音声 · 最終出力 |
| ボーカル処理 | ボーカル分離（UVR / PyMSS）· デリバーブ · ボーカル修復 · 歌声変換 · ハモリ重ね · AI ボーカル強化 |
| 合成と結合 | ミックス · マルチトラック統合 · 順次結合 |
| 音声加工 | オーディオエフェクト · トリム · フェード · 移調 · タイムストレッチ · ラウドネス正規化 |

- ワークフローは**保存・再利用**でき、実行中はノードごとに状態と進捗を表示します。
- ノードの**コピー / 切り取り / 貼り付け**とショートカットに対応し、分離方式を選ぶと対応する分離 / デリバーブノードへ自動で切り替わります。
- 完成音声の行に **「完成音声をダウンロード」** を追加し、`WAV / FLAC / MP3 / M4A` を直接書き出せます。通常モードのプレーヤーへ戻る必要はありません。

## 🎧 リアルタイム変換

- **仮想オーディオケーブルの端点を自動で対応付け**：`CABLE Output` のようなキャプチャ端点を再生可能な `CABLE Input` へ解決し、出力先の選択ミスによる無音を減らします。
- **監視遅延の低減**：オーディオブロックとバッファキューを短縮し、破棄した古いブロックと隣接しない音声とはクロスフェードしないため、直前の古い音が再生されません。
- システム音声デバイスの検出とエラーメッセージを改善し、リアルタイム変換の回帰テストを追加しました。

## 🚀 PyMSS と推論エンジン

- **PyMSS を全機能で統合**：モデルカタログとダウンロード、ボーカル分離、デリバーブ / ハモリ除去に対応し、オーディオエディター・リアルタイム変換・カスタムワークフローのノードで用途別にモデルを絞り込めます。
- **RVC スタックを `rvc-python` から RVC オリジナル実装へ変更**：v1 / v2 設定、HuBERT / RMVPE JIT、推論パイプラインを同梱し、インストーラーとパッケージ構成も合わせて更新しました。
- **変換前のボーカル修復工程を最適化**し、分離から変換までの所要時間を短縮しました。
- **高音保護に高域再構築を追加**：超高域を F0 条件付きボコーダー（Snake-HiFiGAN を優先し、重みがない場合は NSF-HiFiGAN へフォールバック）で再構築し、移調して戻した後の倍音の濁りを軽減します。

## 📦 インストーラーとビルド

- **中国語などの非 ASCII パスでインストールに失敗する問題を修正**：バッチで UTF-8 コードページを固定し、子プロセスがパスを明示的に UTF-8 バイトで出力するため、`for /f` が ANSI で誤解釈して有効な Python や uv を弾かなくなりました。
- **pip のブートストラップキャッシュをインストール先の `.tmp` へ移動**し、システムドライブを圧迫しないようにしました。uv キャッシュも使用前にディレクトリ存在を確認します。
- GitHub Actions の設定を追加・調整し、`setup-uv` のバージョンを固定して CI を再現可能にしました。

## 🏗️ アーキテクチャ、型、テスト

- **DDD の整理を継続**：ルールをドメイン層へ移し、ポート / アダプターの契約を明示し、依存方向をアーキテクチャテストで固定しました。以前の互換用の負債も解消しています。
- `conversion_service`、サービス層、インフラストラクチャの**型注釈を補い**、リリース前のインターフェースずれを検出しやすくしました。
- **不安定なテストを修正**：CI 一時ディレクトリの 8.3 短縮名比較、エンジンソース欠如時の requirements 検証、ダウンロードキャッシュのディレクトリ時刻衝突などです。

## ⚠️ 互換性とアップグレードの注意

> **実行環境**：引き続き Python 3.12 とハードウェア別ランタイム構成（CPU、ROCm 10、DirectML、CUDA 12.6、CUDA 12.8）を使用します。

- 上書きアップグレードでモデル、作品、編集プロジェクト、テーマ、API 設定、プラグインデータは削除されませんが、アップグレード前にユーザーデータディレクトリのバックアップを推奨します。
- ノート単位の**ピッチ再描画**にはボーカル用ランタイム（Praat / Parselmouth）、**F0 解析**には SVC ランタイムが必要です。環境が不足している場合は黙って失敗せず、明示的に通知します。
- 生成されるピッチカーブは**元の基頻が初期値**のため、そのまま適用しても「変更なし」になります。ピッチを補正するにはカーブをノートの中心線へドラッグするか、「カーブを消去」でそのノートを MIDI ピッチへ完全にクオンタイズしてください。
