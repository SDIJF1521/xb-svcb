## v0.0.30 · PyMSS、人声高音保护与环境检测稳定性

> v0.0.30 将 PyMSS 新引擎、本轮环境检测修复与高音保护升级统一纳入同一版本，重点解决“安装器显示存在、软件实际降级”和高音素材翻唱不稳定的问题。

### 🎚️ 新增 PyMSS 人声分离与和声去除

- 创建页新增 UVR / PyMSS 前期人声分离引擎切换；关闭分离时仍可直接进入后续翻唱流程。
- PyMSS 使用独立的 `.venv-pymss` 运行环境和隔离 wheelhouse，避免与 SVC、RVC、UVR 等组件的 Torch 依赖互相覆盖。
- 模型管理页只展示两类 PyMSS 模型：人声分离（`vocal/vocal_extraction`）与和声去除（`legacy_vr/vr_backing_vocal`）。下载后的模型会回到翻唱页供选择。
- 翻唱创建页增加“分离后去除和声 / 伴唱”可选环节。和声模型输出的伴唱轨会从分离人声中相减，保留主唱后再进入 SVC/RVC/SeedVC/DDSP-SVC 推理。
- 未下载的模型不会出现在翻唱页可选列表；模型站下载接口也会拒绝不属于这两类用途的 PyMSS 模型。
- PyMSS 环境或模型缺失时只禁用 PyMSS 选项，UVR 或其他可用引擎仍可继续工作，不阻塞整个应用启动。
- 音频编辑器“人声编辑”面板同步支持 UVR / PyMSS 选择；PyMSS 可在人声分离后继续执行 BVE 和声去除，编辑器从翻唱作品打开时会继承原任务的前期处理配置。

### 🎛️ 音频编辑器性能与时间拉伸

- Element Plus 选择器、操作菜单、开关和原生下拉框统一读取主题语义变量；关闭态控件背景、弹层背景、边框、文字、悬停/选中态会随赛博、二次元和自定义主题同步，不再出现白底选择框或灰色默认开关。
- 波形加载改为优先加载当前片段、最多三个并发请求；缩放或编辑后会丢弃队列中已失效的旧请求。后端一次读取目标区间并使用 NumPy 向量化提取峰值，避免每个采样点启动一次转换。
- 波形转码按源文件大小和修改时间缓存，片段偏移、时长、缩放倍率或源文件变化时自动失效，不会复用旧波形。
- 编辑器片段试听和实时混音预览改用缓存 MP3 传输，减少长音频经 pywebview Base64 桥接时的编码、内存和首播等待；工程导出与复制仍按用户选择保留 WAV/FLAC。
- 片段检查器新增 `25% - 400%` 时间拉伸。倍率同时作用于波形、片段预览、插件监听、实时混音和最终导出；旧工程缺少字段时按 `100%` 兼容。
- FFmpeg `atempo` 会自动拆分到 `0.5 - 2.0` 的安全范围，拉伸不会改变片段在时间轴上的起止位置，也不会截断相邻内容。

### 🚀 PyMSS GPU 与重推理

- PyMSS 使用独立的 Torch 2.7.1 环境：Blackwell 使用 `cu128`，50 系以下 NVIDIA 改用 `cu126`，项目其余引擎仍保留原有 `cu121` 栈，不再把普通 NVIDIA 卡错误安装成 CPU Torch。
- **重要**：这次 `cu126` 只作用于 PyMSS 专属栈，不会把 SVC / RVC / SeedVC / DDSP-SVC 的主安装栈全局改掉。
- wheelhouse 将 PyMSS 依赖放入 `assets/wheels/pymss/py310/<stack>`，约束文件按运行时批次隔离；`--clean` 会清理旧约束，防止历史 Torch 2.5.x 约束触发 `ResolutionImpossible`。
- PyMSS `auto` 在子进程内重新探测实际 Torch 后端，按 CUDA、ROCm、DirectML、MPS 顺序选择；只有显式选择 `cpu` 才强制 CPU，Apple `mlx` 继续使用 PyMSS 原生后端。DirectML 只有在隔离环境实际安装了兼容的 `torch-directml` 时才会启用。
- 当前官方 `torch-directml` 固定 Torch 2.4.1，而 PyMSS 2.0.x 要求 Torch 2.7.1；因此 DirectML 安装栈暂为 PyMSS 准备 CPU Torch，避免伪装成 GPU 就绪或破坏 UVR/SVC 环境。待上游发布匹配版本后可独立替换该批次。
- 编辑器局部重推理支持高音保护。检测到峰值 F0 超过阈值时仅对高音区域降调后推理，再恢复原调；若同时开启 AI 美声，会自动降低高频染色、压缩和激励强度，保留修音与节奏对齐，减少 AI 味。
- 多模型整轨翻唱会汇总各模型的高音保护状态，再对最终美声层使用同一套保守参数。

### 🛠️ 应用环境检测

- 应用端统一验证隔离环境中的真实 Python、Torch 和 worker，不再只根据路径存在判断环境就绪。
- SVC、RVC、SeedVC、DDSP-SVC、UVR、PyMSS、插件和模型站 Python 环境会忽略失效环境变量，并回退到实际存在的安装路径。
- 设备探测结果按 Python 环境签名缓存；环境文件发生变化时自动重新探测，失败结果不再长时间阻塞修复后的状态恢复。
- 首页 PyMSS 状态按模型目录中任一已下载模型判断，不再只检查固定默认模型；创建页提交任务时仍严格校验当前选中的模型。
- 状态页区分基础能力、转换引擎和可选增强组件。FFmpeg 与至少一个转换引擎可运行时显示环境就绪；PyMSS、UVR、AI 歌声增强等可选组件缺失不会误报整个软件降级。

### 📦 安装器与构建

- Python 检测器会清理旧的 `XB_PYTHON_EXE` / `XB_PYTHON_DIR`，逐个执行 3.10+ 版本校验后才导出路径。
- 跳过 WindowsApps 的 Python 执行别名，避免 Microsoft Store 占位程序被显示为已安装。
- 安装器前置页和安装完成校验均执行真实 Python 可运行性检查；各 AI 隔离环境进一步验证 Torch 导入和所选 GPU 栈。
- 构建脚本在生成 wheelhouse 前验证构建机 Python 版本，应用、前端、锁文件、EXE 资源和 Inno Setup 版本统一为 `0.0.30`。

### 🎼 高音保护

- 自动高音保护对超出模型可靠音域的区域执行受限降调翻唱，完成后仅恢复对应区域的原始音高，并补偿高音响度。
- 高音域素材会自动选择更适合的 F0 跟踪路径，降低过度平滑；So-VITS-SVC 和 DDSP-SVC 可使用 FCPE 扩展高音分析范围，最高支持 1800 Hz。
- FCPE 或高音探测失败时回退到兼容的 F0 算法，不阻塞普通翻唱任务；日志会记录选择的路径和回退原因。
- 分离人声与模型输出继续执行高频辅音、高音泛音保护，避免高音区域被过度修复或削弱。
