# 🎉 XB-SVCB v0.1.2 更新说明

#### 工作流商城上线：分享、预览、下载与 PyMSS 联动

[![release](https://img.shields.io/badge/release-v0.1.2-ff6b9d?style=flat)](../../README.md)
[![date](https://img.shields.io/badge/date-2026--11--21-informational?style=flat)](#)

</div>

> **一句话概括：** 新增基于魔搭社区（ModelScope）的工作流商城，支持上传、分页搜索、只读预览和下载工作流；下载时自动同步清单中的 PyMSS 模型，并可直接在 AI 翻唱工作台载入。同时重做了工作流预览与全站弹窗样式，并修复下载工作流连线被错误裁剪的问题。

## ✨ 亮点速览

| 方向 | 本版变化 |
| :--- | :--- |
| 🛍️ **工作流商城** | 全新：上传自己的已保存工作流 · 搜索 / 分页浏览 · 只读预览 · 下载他人或自己的公开工作流 |
| 🔗 **PyMSS 联动** | 下载工作流时自动安装清单声明的缺失 PyMSS 模型，已安装的自动跳过 |
| 🎛️ **工作台联动** | 下载后写入「已保存工作流」；「前往 AI 翻唱工作台」自动进入工作流模式并载入该工作流 |

| 🪟 **弹窗体验** | 统一 MessageBox / Dialog 的居中、背景、边框、按钮与长文本排版 |
| 🧱 **架构收束** | 工作流商城清单规则下沉领域层，ModelScope 网络 / 上传落到适配层，用例层只做编排 |

## 🛍️ 工作流商城

- 工作流商城入口位于「资料库 → 工作流商城」，与模型站共用 ModelScope 访问令牌。
- 支持上传「已保存工作流」，清单记录节点图、简介、标签、版本、作者和依赖的 PyMSS 模型。
- 搜索支持关键词、全部 / 我上传的工作流筛选、每页条数与分页查询；分页栏固定在页面底部。
- 分页统计只计算工作流仓库，不再把自己的声音模型数量混入「我上传的工作流」。
- 商城只展示通过清单 magic 校验的工作流，避免无关模型污染结果。

## 🔗 与 PyMSS、工作台联动

- 工作流详情会列出相关 PyMSS 模型及本地安装状态。
- 下载工作流后先写入「已保存工作流」，再同步安装缺失的 PyMSS 模型；失败项会在传输中心提示，可稍后重试。
- 「前往 AI 翻唱工作台」会携带本地工作流 ID，自动切换到自定义工作流模式并载入该工作流。
- 下载工作流首次打开时会自动整理画布布局，减少作者原始坐标造成的交叉连线；可用撤销恢复。

## 🖼️ 预览与弹窗

- 商城工作流预览改为按拓扑分层布局，不再直接使用作者画布坐标。
- 节点标题单行省略、参数说明最多两行，模型名不会再撑出卡片。
- 预览带方向箭头、主题化背景与卡片，并按节点图比例自适应高度。
- 全站 `ElMessageBox` 统一为 flex 居中、明确宽度与主题化按钮，修复部分环境确认框跑到左上角、透明和按钮错位的问题。
- `el-dialog` 同步统一玻璃背景、圆角、阴影和遮罩模糊。

## 🔧 重要修复

- 修复从工作流商城下载的工作流在自动载入时，PyMSS 模型目录尚未返回导致有效连线被当作失效端口删除的问题。
- 模型目录加载完成后重新测量端口位置，避免连线落在节点角落。
- 清单边 ID 缺失或重复时生成唯一兜底值，避免画布按 key 复用导致连线错乱。
- 修复「我上传的工作流」统计混入声音模型的问题。
- 修复下载确认框等 MessageBox 在部分主题 / 环境下布局异常的问题。

## 🧱 架构与质量

- 新增 `domain/workflow_manifest.py`：清单校验、节点图收敛、PyMSS 依赖解析与来源信息规整。
- 新增 `infrastructure/workflow_hub_client.py`：实现 ModelScope 搜索、清单读取与子进程上传。
- `application/workflow_hub_service.py` 仅保留用例编排；PyMSS 安装状态通过 `PymssGateway` 端口访问。
- 新增领域层、用例层与端口契约测试，并同步更新 DDD 架构文档。

## 📌 升级注意

- 本版版本号统一为 `0.1.2`，数据目录与已有模型、作品、编辑器工程兼容。
- 如果旧版本打开过商城下载的工作流并在画布上点过「保存」，旧的本地副本可能已缺少连线；升级后重新下载一次该工作流即可恢复完整连线。
- 工作流商城的上传需要 `.venv-hub` 中的模型上传组件；搜索、预览与下载不需要该组件。
