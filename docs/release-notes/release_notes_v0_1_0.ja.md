# XB-SVCB v0.1.0 リリースノート

[简体中文](release_notes_v0_1_0.md) | [English](release_notes_v0_1_0.en.md) | **日本語**

`0.1.0` は、アプリUI、インストーラー、リリースノートを簡体字中国語、英語、日本語で同時に提供する最初のXB-SVCBリリースです。作成フロー、オーディオエディター、推論保護、テーマ、配布手順を重点的に改善し、アプリとインストーラーのバージョンを `0.1.0` に統一しました。

このリリースの変更範囲はコミット `fc8d214e068457a273929e80c108b33f55b4e9e8`（「全パラメーターの話者入力欄を選択式に変更」）を含めて開始します。コミット一覧の生成や差分監査には次の範囲を使用してください。

```text
fc8d214e068457a273929e80c108b33f55b4e9e8^..HEAD
```

`0.1.0` 以降の各リリースでは、同じ変更範囲と互換性要件を記載した簡体字中国語、英語、日本語のリリースノートを同時に公開します。

## UIと言語

- 簡体字中国語、英語、日本語のUI切り替えを追加しました。選択は保存され、Vue画面とElement Plusコンポーネントの初期化前に適用されるため、起動時の言語表示切り替わりを抑えます。
- ホーム、作成、エディター、作品、モデル、プラグイン、ボーカル強化、API管理の主要フローに英語と日本語の表示を追加しました。
- 英語と日本語の長いラベルに合わせてボタン、選択欄、フォーム、エディターパネルを調整し、文字切れや隣接コントロールとの重なりを防ぎます。
- 初回ガイドを37個の細かな手順から10個のワークフロー手順へ整理し、モデル準備、タスク作成、編集と書き出しの要点を維持しました。
- テーマ切り替え時にページ幅が変化して発生する横揺れを修正し、テーマ遷移とネイティブウィンドウ背景の同期を改善しました。

## 作成と推論

- 全パラメーターモードの話者自由入力を、モデルが提供する選択肢に変更しました。So-VITS-SVCはモデル設定から話者名を読み取り、DDSP-SVCはモデルが宣言する話者数から番号を生成します。
- モデル設定の破損、異常な話者数、話者情報の欠落時は空の選択肢へ安全にフォールバックし、使用不能な巨大リストを生成しません。
- 通常変換では、全パラメーターモードで高音保護の再試行回数が `0` の場合、システムが既定回数を使用します。リアルタイム変換では従来どおり `0` は再試行なしを意味します。
- 高音保護は極端な高音域をフォルマントを保ったまま一度下げ、推論後に元の音高へ戻してラウドネスを補正します。再試行時は検出した無音化位置に応じて内部保護境界を調整します。
- RVC v1/v2の構造判定と互換性警告を追加しました。確実に判定できない場合はモデルバージョンを無言で変更せず、既存の互換設定を維持します。
- API画面に高音保護、全パラメーター調整、エディター局所再推論の範囲、既定値、通常/リアルタイム動作の違いを追加しました。

## オーディオエディター

- タイムラインの空白、トラック、クリップにコンテキストメニューを追加し、その位置から一般的なクリップ、トラック、エフェクト操作を実行できるようにしました。
- エフェクトをクリップ、トラック全体、ロールの3スコープに分離しました。各スコープで有効化、バイパス、調整、削除を個別に行い、レンダリング時もルーティング境界を維持します。
- スコープ別エフェクトバス、プラグインエディター同期、モニタープレビュー、不正なプラグイン出力をドライ信号へ自動バイパスする保護を追加しました。
- 局所再推論に段階別進捗、状態説明、追記式ログを追加しました。タスク実行中にモデル検証、推論、クリップ置換の状態を確認できます。
- 再推論後も適用可能なクリップエフェクトを保持します。安全に再適用できないプラグインエフェクトは、無断で二重適用せずプロジェクトメタデータへ記録します。
- エディターパネル、タイムライン選択、プロジェクト一覧、再生操作、レスポンシブレイアウトを改善しました。

## テーマとアセット

- 組み込みテーマを追加・調整し、既定のブランドアセットを更新しました。アプリとインストーラーは `web/public/favicon.ico` を共通アイコンとして使用します。
- カスタム背景はJPG、PNG、WebP、GIF、AVIF、HEIC/HEIF、MP4に対応します。メディアをアプリのテーマディレクトリへ保存し、ブラウザーのローカルストレージ容量に制限されなくなりました。
- 大きな静止画はFFmpegで自動的に縮小・変換し、起動時メモリと設定サイズを抑えます。テーマメディア操作はテーマディレクトリ内に限定し、外部ファイルの誤削除を防ぎます。
- カスタムテーマにオーバーレイ強度、画像/動画種別、パーティクル設定を追加し、テーマ変更後にネイティブウィンドウの色も同期します。

## インストーラーとオンラインセットアップ

- オフラインインストーラーは簡体字中国語、英語、日本語に対応します。Windows UI言語を初期選択し、ユーザーは常に言語を変更できます。
- ウィザード、依存関係チェック、ハードウェア選択、同梱Pythonの検証、データディレクトリ、進捗、エラー、ランタイム検証、完了画面、ショートカットは同期された3言語のメッセージキーを使用します。
- 5種類すべてのオフラインインストーラーに、クリーンな64ビットCPython 3.12.xと完全なFFmpeg/ffprobeを同梱します。インストールと後の修復はグローバルPython/FFmpegに依存せず、同梱ランタイムを固定して使用します。
- 低速なGPUや初回のコールドスタートでDDSPの読み込みが45秒を超え、CUDA共有ランタイムが誤って失敗する問題を修正しました。共有セットアップは通常のimportに90秒、DDSPの初回起動に180秒を許可します。タイムアウトは明示的な失敗として記録され、不完全な `runtime.json` は有効化されません。
- 簡体字中国語と日本語のInno Setup言語ファイルをリポジトリに含め、ビルドPCの追加言語パックに依存しないようにしました。
- CPU、NVIDIA CUDA 12.6/12.8、AMD ROCm 10を検出し、DirectML互換モードも明示的に選べる軽量オンラインインストーラーを追加しました。選択した1種類のオフラインパッケージだけをダウンロードします。
- DirectMLパッケージへ `pymss/py312/cpu` を復元しました。PyMSSは独立 `.venv-pymss` でCPU Torch 2.7.1を使用し、`torch-directml`が固定するTorch 2.4.1とは混在しません。
- オンラインマニフェストは各EXE/BINのサイズとSHA-256を固定し、ブートストラッパーはマニフェストのSHA-256を固定します。すべての検証が成功してからオフラインインストーラーを起動します。
- 公開OSS HTTPS URLはビルド時に注入され、AccessKey、Secret、長期署名URLはインストーラーに含めません。
- 5スタックのwheelhouse準備を増分方式に変更しました。`-CleanWheelhouse` を明示した場合だけキャッシュを削除し、中断したダウンロードは指定バッチから再開できます。
- CPUのSVC/RVCコンポーネントをROCmバッチより先に準備し、AMD配布元の障害後にCPUパッケージの不足が判明する問題を防ぎます。
- ROCmコンポーネントは共有Torch/SDK wheelをハードリンクで再利用し、PyMSSやDDSPなどの重複ダウンロードとディスク使用量を削減します。

## モデルとリポジトリ

- Gitリポジトリは `assets/models/` 配下のモデル重み、マニフェスト、設定を追跡しません。モデルは外部モデルコミュニティで管理し、リリースビルド前にローカルへ同期する必要があります。
- オフラインインストーラーは、ローカルで準備した完全な `assets/models/` を引き続き同梱できます。Gitの除外規則はインストーラーによるローカルファイルの読み取りを妨げません。
- モデル、作品、編集プロジェクト、テーマ、API設定、プラグインデータは既存のデータディレクトリを継続利用し、上書き更新で意図的に削除しません。

## 開発とドキュメント

- ルートREADME、ユーザーガイド、開発ガイド、API資料、プラグイン資料に簡体字中国語、英語、日本語の入口を用意しました。
- Pythonのサービス、基盤、インストールスクリプト、wheelhouseツールへ型注釈を追加し、Pyright設定でリリース前のインターフェースずれを検出しやすくしました。
- 翻訳キー整合性、インストーラー3言語メッセージ、RVCモデル判定、推論デバイス、テーマメディア、エフェクトスコープ、インストーラーランタイム計画のチェックを追加しました。
- バックエンド、Pythonパッケージとロックファイル、フロントエンドとロックファイル、PyInstallerリソース、インストーラーのバージョンを `0.1.0` に統一しました。

## 互換性と更新時の注意

- Python 3.12とハードウェア別ランタイム構成を継続し、CPU、ROCm 10、DirectML、CUDA 12.6、CUDA 12.8のインストール構成を提供します。
- DirectMLは主に互換経路です。DDSPの自動デバイス選択は引き続きCPUを優先し、明示的に選択した実験的DirectML出力は使用前に試聴してください。
- オンラインインストーラーは設定済みOSS/HTTPSエンドポイントへの接続が必要です。完全オフライン環境では、対象ハードウェアのEXEと同じ接頭辞を持つすべてのBIN分割ファイルを取得してください。
- 旧版から更新する前にユーザーデータディレクトリのバックアップを推奨します。既存のモデル、作品、編集プロジェクトは移行・削除しませんが、外部モデル保管は配布者またはユーザーが管理する必要があります。

セットアップと修復は[インストールと起動](../ja/getting-started.md)、ビルド、オンライン公開、OSS設定は[インストーラー文書](../../installer/README.md)を参照してください。
