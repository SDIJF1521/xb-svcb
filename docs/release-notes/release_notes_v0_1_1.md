## 🎼 MIDI 子编辑器

- **音符级音高重绘**：从片段音频提取音符，按音符把音高重绘回音频。重绘在隔离的美声环境中以 Praat PSOLA 执行，保留共振峰与音色，只改动被拖动的音符，未修改的音符维持原始音准。
- **两种工作模式**：「演唱音准」修正已有演唱；「MIDI 编曲」从零写谱。编曲模式内置 128 件 GM 乐器与 GM 鼓组，鼓件使用从 `gm.dls` 提取的真实采样，并按底鼓、军鼓、踩镲、吊镲等分组吸附。
- **完整时间轴**：BPM、拍号、时长、网格与量化强度。时长可手动填写（上限 24 小时），音符写到更远处自动延长；新增空白工程入口，空轨道也能直接编曲并渲染出音频。
- **顺手效率**：右键菜单（添加 / 删除 / 复制 / 粘贴 / 量化 / 移调 / 力度 / 连奏 / 拆分 / 全选 / 撤销重做）与快捷键（`D` 画笔、`V` 选择、`E` 橡皮、`Ctrl+C/V/D/A/Q/Z`、`Alt+↑↓`、`Shift+↑↓`、`Del`、空格试听），以及「渲染到本轨」「渲染为分乐器音轨」「导出 .mid」「导入 .mid 到声部」。
- **音高曲线（滑音 / 颤音）**：在音符上拖动即可在原唱基频基础上手绘曲线，并提供「颤音」「滑音」「取原始音高」「清除曲线」快捷操作。曲线以原唱 F0 为初值，可反复增量修改，全程支持撤销 / 重做。
- **局部整形**：可在指定位置拆分音符，并让音高曲线在切点一并断开，便于只对某个片段单独处理。
- **按绝对目标音高重绘**：曲线直接描述目标音高，不再把原唱自身的偏差叠加第二次 —— 修复了默认曲线渲染后出现原本不存在的滑音、颤音被放大的问题。
- **原始音高更可信**：F0 先做野值清理（局部中值滤波剔除整帧跳八度与爆音），再作为参考曲线叠加显示，方便对照「唱的是哪里」与「音符写的是哪里」。

## 🎚️ 音频编辑器

- 新增**音轨重命名**。
- 修复**导出路径控件撑高时间线顶栏**、挤压工具栏导致布局被破坏的问题；窄屏下改为换行布局，路径超长自动省略。
- **角色「变调」真正参与渲染**：非零变调的角色会单独走一条角色总线并做保持时长的整体变调，同时把该值纳入混音缓存签名，改完不会继续复用旧缓存。
- 顶部**消息提示统一下移到导航栏下方**，不再遮挡导航与搜索框。
- 编辑器交互、VST3 插件主机、角色效果作用域与局部重推理细节同步优化。

## 🧩 AI 翻唱工作台：自定义工作流

在画布上自由连线，把整条翻唱流水线摊开编排：

| 类别 | 节点 |
| :--- | :--- |
| 输入 / 输出 | 输入音频 · 输出成品 |
| 人声处理 | 人声分离（UVR / PyMSS）· 去混响净化 · 人声修复 · 歌声转换 · 人声合唱叠加 · AI 歌声增强 |
| 合成与拼接 | 混音合成 · 多轨混合 · 顺序拼接 |
| 音频加工 | 音频效果 · 裁剪片段 · 淡入淡出 · 变调 · 变速 · 响度归一化 |

- 工作流可**保存与复用**，运行时按节点显示状态与进度。
- 节点支持**复制 / 剪切 / 粘贴**与快捷操作；选择分离方式时自动切换到对应的分离 / 去混响节点。
- 成品试听行新增 **「下载成品」**，可直接导出 `WAV / FLAC / MP3 / M4A`，不必再绕回普通模式的播放器。

## 🎧 实时翻唱

- **虚拟声卡端点自动配对**：把常见的 `CABLE Output` 之类采集端点自动映射到可播放的 `CABLE Input`，减少「输出选错所以没声音」。
- **更低监听延迟**：音频块与缓冲队列缩短；丢弃过期块时不再与不连续的音频做交叉淡化，避免开头回放上一段旧声音。
- 改进系统音频设备识别与错误提示，并补充实时翻唱的回归测试。

## 🚀 PyMSS 与推理引擎

- **PyMSS 全功能接入**：模型目录与下载、人声分离、去混响 / 和声去除，并在音频编辑器、实时翻唱与自定义工作流节点中按用途筛选可用模型。
- **RVC 技术栈由 `rvc-python` 换回 RVC 原始项目实现**：内置 v1 / v2 配置、HuBERT / RMVPE JIT 与推理管线，安装与打包脚本同步调整。
- **前期人声修复流程优化**，缩短从分离到可转换的总时长。
- **高音保护新增高频带重建**：在极高音区使用 F0 条件化声码器（优先 Snake-HiFiGAN，缺失权重时回退 NSF-HiFiGAN）重建超高频带，减少先降调再升回后的谐波糊化。

## 📦 安装器与构建

- **修复中文（及非 ASCII）安装路径下安装失败**：批处理固定 UTF-8 代码页，子进程显式以 UTF-8 字节输出路径，避免 `for /f` 按 ANSI 解码产生乱码后误判 Python 与 uv 位置。
- **pip 引导缓存移到安装目录 `.tmp`**，不再占用系统盘；uv 缓存使用前确认目录存在。
- 新增并调整 GitHub Actions 配置，固定 `setup-uv` 版本，保证 CI 可复现。

## ⚠️ 兼容性与升级提示

> **运行环境**：继续使用 Python 3.12 与硬件专用运行时布局，安装配置仍为 CPU、ROCm 10、DirectML、CUDA 12.6 与 CUDA 12.8。

- 覆盖升级不会删除模型、作品、编辑工程、主题、API 设置与插件数据；升级前仍建议备份用户数据目录。
- MIDI 子编辑器的**音符级音高重绘**依赖美声运行时（Praat / Parselmouth），**F0 分析**依赖 SVC 运行时；缺少对应环境会明确提示，不会静默失败。
- 音高曲线**初次生成即以原唱基频为初值**，直接应用等于「不改动」。需要修音准时，把曲线拖向音符中线，或用「清除曲线」把该音符完全量化到 MIDI 音高。
